Should и shouldn't: советы по-английски (A2)

Когда хочешь кому-то что-то посоветовать — «тебе стоит…», «лучше не надо…» — в английском нужен should и shouldn't. Это самая частая конструкция для советов: на работе, при переезде, в переписке с коллегами.

  1. После should и shouldn't глагол стоит в базовой форме, без to: You should apply, а не You should to apply.
  2. Should — это «стоит, советую»: You should update your CV. Это не приказ, поэтому звучит вежливо.
  3. Shouldn't — «не стоит, лучше не надо»: He shouldn't quit his job now.
  4. Вопрос-совет строится так: Should + кто + глагол: Should I write to them?
  5. Для усиления добавляй really перед should: You really should practise English.
  6. Should не меняется: с he, she, it тоже should, без -s: She should try.

Примеры

  • Dima, you should put your GitHub on your CV.Дима, тебе стоит добавить свой GitHub в резюме.
  • Anya shouldn't send that message before the interview.Ане не стоит отправлять это сообщение до собеседования.
  • Should I ask the recruiter about relocation?Мне стоит спросить рекрутера о релокации?
  • You really should learn English if you want to work abroad.Тебе правда стоит учить английский, если хочешь работать за границей.
  • Kirill should talk to his team lead about the deadline.Кириллу стоит поговорить с тимлидом о дедлайне.
  • We shouldn't book the tickets before we get the offer.Нам не стоит покупать билеты, пока мы не получим оффер.

Частые ошибки

You should to learn English.
You should learn English.
После should нет to — только глагол в базовой форме.
She shoulds to work harder.
She should work harder.
Should не меняется по лицам: никакого -s и никакого to.
You shouldn't to panic.
You shouldn't panic.
После shouldn't тоже глагол без to.

Проверь себя

  1. You ___ check the job description before the interview.

  2. Petya ___ miss the online meeting tomorrow.

  3. ___ I ask about the salary in the first message?

  4. Vika ___ update her LinkedIn profile.

  5. You really ___ sleep before the final interview.
