Second conditional: If I had more time, I would travel — правило B1

Second conditional нужен, когда ты фантазируешь или говоришь о том, что вряд ли произойдёт: If I had more time, I would travel. Это мечты, гипотезы и советы «на твоём месте» — про настоящее или будущее, а не про прошлое. Для переезда и работы в IT это главная конструкция для разговоров в духе «если бы у меня был оффер…».

  1. Схема такая: If + Past Simple, затем would + глагол в первой форме: If I knew English better, I would apply for this job.
  2. В части с If глагол стоит в Past Simple, но речь о настоящем или будущем — это «ненастоящее» прошедшее: If I lived in Berlin… = «если бы я жил в Берлине сейчас».
  3. С I / he / she / it в If-части можно использовать were: If I were a developer, I would work remotely. В разговорной речи встречается was, но were — правильный вариант.
  4. Порядок частей свободный: I would move abroad if I found a good offer. Запятая нужна только когда If-часть стоит первой.
  5. В основной части нельзя ставить will: только would (или could / might, если нужен оттенок «смог бы / возможно»): If I had a visa, I could start tomorrow.
  6. В If-части не бывает would: If I would have time — неверно, нужно If I had time.

Примеры

  • If I had more free time, I would learn German for work in Berlin.Если бы у меня было больше свободного времени, я бы учил немецкий для работы в Берлине.
  • If Anna spoke better English, she would pass the IT interview easily.Если бы Анна лучше говорила по-английски, она бы легко прошла IT-собеседование.
  • I would relocate to Poland if the company paid for the visa.Я бы переехал в Польшу, если бы компания оплачивала визу.
  • If I were you, I would send your CV to that startup today.На твоём месте я бы отправил резюме в этот стартап сегодня.
  • We could work from Lisbon if our team allowed remote work.Мы могли бы работать из Лиссабона, если бы наша команда разрешала удалёнку.
  • If Dmitry didn't have a mortgage, he would try freelancing abroad.Если бы у Дмитрия не было ипотеки, он бы попробовал фриланс за границей.

Частые ошибки

If I will have more time, I would travel.
If I had more time, I would travel.
После If в second conditional не ставим will — нужен Past Simple: had.
If I would know English, I would move to Canada.
If I knew English, I would move to Canada.
would живёт только в основной части, а в If-части — Past Simple: knew.
If I were a tester, I will earn more.
If I were a tester, I would earn more.
В результате условия нужен would + глагол, а не will: ситуация нереальная.

Проверь себя

  1. If Sergey ___ more time, he would study for the AWS certificate.

  2. If I spoke fluent English, I ___ apply for a job in London.

  3. If Olga ___ in Berlin, she would go to meetups every week.

  4. I would change my job if I ___ a better offer.

  5. If I ___ you, I would ask for a remote contract.
