Zero conditional: если нагреть лёд, он тает — простое правило

Zero conditional — это про то, что происходит всегда: законы природы, правила, привычные реакции. Если условие выполнено, результат получается автоматически, без вариантов. В английском обе части идут в present simple: If you heat ice, it melts.

  1. Схема простая: If + present simple, затем present simple: If you press this button, the program closes.
  2. Если действие всегда верно, can ставить when вместо if — смысл почти тот же: When you heat ice, it melts.
  3. Запятая нужна, когда if-часть стоит первой. Если первой идёт результат — запятая не нужна: Ice melts if you heat it.
  4. В обеих частях — только present simple, без will и would: If it rains, the streets get wet.
  5. Местоимение you здесь значит «ты/любой человек»: If you don't save the file, you lose your work.
  6. Для общих фактов и инструкций это самый частый вариант — от погоды до кода: If the server is down, all users see an error.

Примеры

  • If you heat ice, it melts.Если нагреть лёд, он тает.
  • If Anna forgets her password, she clicks "Reset".Если Анна забывает пароль, она нажимает «Сбросить».
  • The build fails if you don't fix the tests.Сборка падает, если не исправить тесты.
  • When Dmitry works from home, he starts at nine.Когда Дмитрий работает из дома, он начинает в девять.
  • If the internet is slow, video calls freeze.Если интернет медленный, видеозвонки зависают.
  • If you mix red and yellow, you get orange.Если смешать красный и жёлтый, получится оранжевый.

Частые ошибки

If you heat ice, it will melt.
If you heat ice, it melts.
Это общий закон природы — нужен present simple, а не will.
If you will press Ctrl+S, the file saves.
If you press Ctrl+S, the file saves.
После if в zero conditional will не ставим — только present simple.

Проверь себя

  1. If you ___ water to 100 °C, it boils.

  2. If Sergey ___ the wrong branch, the deploy fails.

  3. Plants die if they ___ enough light.

  4. When you ___ this link, the page opens in a new tab.

  5. If the code ___ a bug, the tests show red.
