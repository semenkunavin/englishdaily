Конструкция Would like: I'd like a coffee — английский для работы

Конструкция would like — это вежливое «хотел бы». Её используют, когда заказывают еду и кофе, говорят о планах и просят что-то на работе. Запомни главное: would like — это не то же самое, что like («нравиться»).

  1. После would like идёт существительное или to + глагол: I'd like a coffee, I'd like to talk.
  2. I'd like = I would like: это вежливая форма, не прошедшее время. Сокращение 'd — норма в разговоре.
  3. Не путай: I like coffee — «мне нравится кофе» (всегда), I'd like a coffee — «я хотел бы кофе» (сейчас).
  4. Вопрос: Would you like a coffee? — «Хочешь кофе?». Вопрос про действие: Would you like to join us?
  5. Чтобы попросить конкретную вещь: I'd like a large coffee, please. С please звучит ещё вежливее.
  6. В ресторане и кафе так делают заказ носители: I'd like the soup and a coffee, please — без I want.

Примеры

  • I'd like a coffee, please.Я бы хотел кофе, пожалуйста.
  • Would you like a cup of tea, Инна?Хочешь чашку чая, Инна?
  • Данил would like to work in Berlin.Данил хотел бы работать в Берлине.
  • I'd like to ask a question about the project.Я хотел бы задать вопрос о проекте.
  • Would you like to see the menu?Хотели бы вы посмотреть меню?
  • Мария would like a new laptop for work.Мария хотела бы новый ноутбук для работы.

Частые ошибки

I'd like a coffee I'd like a tea.
I'd like a coffee and a tea.
Два простых предложения нельзя ставить без союза: между ними нужен and или точка.
I would like have a coffee.
I would like to have a coffee.
После would like перед глаголом обязательно to: would like to have.
I like a coffee now, please.
I'd like a coffee now, please.
like — «нравиться» вообще; разовое желание сейчас — только would like.

Проверь себя

  1. I ___ like a coffee, please.

  2. Would you like ___ the menu?

  3. Ильдар ___ like to move to Canada for a job.

  4. What would you like ___ eat?

  5. Я бы хотел воду без газа. = I'd like still ___.
