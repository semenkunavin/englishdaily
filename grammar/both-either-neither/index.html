Both, either и neither — просто для тех, кто едет работать за границу

Это три слова про «два»: both — «оба», either — «любой из двух», neither — «ни один из двух». Они нужны каждый день: на собеседовании, в офисе, когда выбираешь между двумя офферами или двумя технологиями. Запомни раз и навсегда: both — про двух сразу, either и neither — про выбор из двух.

  1. both = оба, и тот и другой. После него существительное во множественном числе: both offers, both options.
  2. either = любой из двух, один из двух. После него существительное в единственном числе: either offer, either way.
  3. neither = ни один из двух (то есть ни тот, ни другой). Тоже единственное число: neither option.
  4. Перед существительным с both / either / neither артикль не ставим: both companies, а не both the companies.
  5. Сокращение: neither = not either. Поэтому I don’t like either = I like neither — смысл один.
  6. both … and … — «и … и …», either … or … — «или … или …», neither … nor … — «ни … ни …»: both Sasha and Dima, either Sasha or Dima, neither Sasha nor Dima.

Примеры

  • Both offers are good, but I want to work abroad.Оба оффера хорошие, но я хочу работать за границей.
  • You can take either laptop — they are the same.Можешь взять любой ноутбук — они одинаковые.
  • Neither candidate knows Python.Ни один из двух кандидатов не знает Python.
  • I don’t speak either language, but I’m learning English.Я не говорю ни на одном из двух языков, но учу английский.
  • Both Masha and Oleg work in IT.И Маша, и Олег работают в IT.
  • Neither the recruiter nor the manager answered my email.Ни рекрутер, ни менеджер не ответили на моё письмо.

Частые ошибки

Both of the options is fine.
Both options are fine.
После both — множественное число и глагол во множественном: both options are.
I can choose either offers.
I can choose either offer.
После either и neither существительное в единственном числе: either offer.
I don’t know neither of them.
I don’t know either of them.
В английском нельзя два отрицания: don’t + neither не вместе, нужно either.

Проверь себя

  1. ___ of my colleagues speak German, so we use English at work.

  2. You can start on Monday or on Wednesday — ___ day is fine.

  3. ___ Sasha and Dima moved to Berlin for a new job.

  4. I have two job offers, but ___ one is remote.

  5. Choose ___ Python or Java for this project — not both.
