First conditional по-английски: If it rains, I will stay home

First conditional нужен, когда ты говоришь о реальном будущем: «если будет дождь, я останусь дома». Схема простая: if + present simple в одной части, will + глагол в другой. Это самая частая конструкция для планов, условий и обещаний — пригодится и на собеседовании в IT, и при переезде.

  1. Формула: If + Present Simple, will + глагол. Порядок частей можно менять, смысл тот же.
  2. В части с if будущее не ставим: If it rains, а не If it will rain.
  3. Запятая нужна, когда if-часть стоит первой: If you come, I will help you. Если первой идёт часть с will — запятая не нужна.
  4. В части с will глагол всегда в базовой форме: will stay, will not (won't) stay.
  5. Вопрос строится по части с will: Will you stay home if it rains?
  6. Сокращения обычные: I'll, she'll, won't. В части с if можно и doesn't, и isn't.

Примеры

  • If it rains tomorrow, I will stay home.Если завтра будет дождь, я останусь дома.
  • If Anna passes the interview, she will move to Berlin.Если Анна пройдёт собеседование, она переедет в Берлин.
  • We will start the meeting at 10 if Dmitry is not late.Мы начнём встречу в 10, если Дмитрий не опоздает.
  • If you don't understand the code, I will explain it.Если ты не понимаешь код, я объясню.
  • I will send you the CV if you give me your email.Я отправлю тебе резюме, если ты дашь мне свой email.
  • Will Sergey join us if we meet online?Сергей присоединится к нам, если мы встретимся онлайн?

Частые ошибки

If it will rain, I will stay home.
If it rains, I will stay home.
После if — только present simple, не will.
If it rains, I stay home tomorrow.
If it rains, I will stay home tomorrow.
О будущем результате нужен will + глагол.
If I will get the job, I will relocate.
If I get the job, I will relocate.
В условии с if будущее не ставим: if I get.

Проверь себя

  1. If it ___, we will cancel the picnic.

  2. If Olga ___ the visa, she will fly to Canada.

  3. I will call you if I ___ late.

  4. If you finish the task early, we ___ the code together.

  5. ___ Maxim come to the interview if we reschedule it?
