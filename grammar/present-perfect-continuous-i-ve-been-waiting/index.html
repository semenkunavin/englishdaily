Present perfect continuous: I've been waiting — правило для B1

Present perfect continuous — это когда действие началось раньше и всё ещё продолжается (или только что закончилось, и виден результат). По-русски мы говорим «я жду уже полчаса», а по-английски — I've been waiting for half an hour. Особенно полезно на работе за границей и в IT: рассказать, над чем работаешь, сколько времени учишься, почему устал.

  1. Формула: have/has + been + V-ing. I / you / we / they → have been, he / she / it → has been: She has been coding since morning.
  2. Действие началось в прошлом и идёт сейчас — используем for (длительность) и since (точка старта): for two hours, since 2022, since Monday.
  3. Вопрос строится перестановкой: Have you been waiting long? / How long has he been working here?
  4. Отрицание: haven't been / hasn't been + V-ing: I haven't been sleeping well this week.
  5. Если важен только результат, а не процесс, чаще берут Present Perfect: I've written the code (готово) vs I've been writing the code (писал, процесс).
  6. С know, like, want, have (владеть) continuous обычно не ставят — там Present Perfect: I've known Dima for years.

Примеры

  • I've been waiting for the bus for twenty minutes.Я жду автобус уже двадцать минут.
  • Anya has been learning Python since January.Аня учит Python с января.
  • How long have you been working at this startup?Как долго ты работаешь в этом стартапе?
  • We've been looking for an apartment in Berlin all week.Мы всю неделю ищем квартиру в Берлине.
  • Sorry, I'm tired — I've been debugging this service all day.Извини, я устал — я весь день отлаживаю этот сервис.
  • Maksim hasn't been feeling well since Friday.Максим плохо себя чувствует с пятницы.

Частые ошибки

I am waiting for the bus for twenty minutes.
I've been waiting for the bus for twenty minutes.
Если есть for twenty minutes, нужен have been + V-ing, а не Present Continuous.
She has been work here since 2022.
She has been working here since 2022.
После been обязателен V-ing: been working.
I've been knowing Dima for years.
I've known Dima for years.
know — глагол состояния, с ним Present Perfect, без been ...-ing.

Проверь себя

  1. I ___ for the interview result since Monday.

  2. How long ___ in Minsk?

  3. Olga ___ at the IT company for three years.

  4. They ___ for a new flat all month.
