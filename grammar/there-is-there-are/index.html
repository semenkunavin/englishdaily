There is / there are: оборот для «есть, находится» в английском (A1)

Оборот there is / there are нужен, когда ты говоришь, что что-то есть или чего-то нет: «в офисе есть кухня», «на столе два ноутбука». По-русски мы часто говорим «есть» или вообще без слова, а в английском на этом месте почти всегда стоит there is или there are.

  1. There is + один предмет (there is a printer): одно, единственное число.
  2. There are + много предметов (there are two laptops): два и больше.
  3. Отрицание: there isn't / there aren't или there is no + существительное (there is no Wi-Fi).
  4. Вопрос: Is there…? / Are there…? — is/are уходит вперёд (Is there a meeting room?).
  5. Короткий ответ: Yes, there is / No, there isn't / Yes, there are / No, there aren't.
  6. Перед there is можно ставить some или any с неисчисляемыми и множественными словами: there is some coffee, are there any questions?

Примеры

  • There is a coffee machine in the kitchen.На кухне есть кофемашина.
  • There are three developers on our team.В нашей команде три разработчика.
  • Is there a parking near the office?Рядом с офисом есть парковка?
  • There aren't any tickets for Friday.На пятницу нет билетов.
  • There is no Wi-Fi in the basement.В подвале нет Wi-Fi.
  • There are two Tanyas and one Dmitry in the chat.В чате две Тани и один Дмитрий.

Частые ошибки

There is three developers on our team.
There are three developers on our team.
Три — это много, значит there are, а не there is.
Have a coffee machine in the kitchen.
There is a coffee machine in the kitchen.
Чтобы сказать «есть/находится», нужен оборот there is, а не have без подлежащего.
Is there any tickets for Friday?
Are there any tickets for Friday?
Tickets — множественное число, поэтому вопрос начинается с Are there.

Проверь себя

  1. ___ a laptop on the desk.

  2. ___ five people in the meeting room.

  3. ___ any coffee in the kitchen?

  4. ___ a printer on the second floor.

  5. ___ any questions about the project?
