Some и any в английском: простое правило для A1

Some и any — это слова «немного, несколько, какие-то». Они нужны, когда говоришь о количестве, но не называешь точное число. По-русски ты часто вообще не переводишь их: «У меня есть время» — I have some time.

  1. В утверждениях ставим some: I have some questions.
  2. В вопросах и отрицаниях ставим any: Do you have any questions?, I don't have any questions.
  3. В вопросах some — когда предлагаешь или просишь: Would you like some coffee?
  4. Перед неисчисляемыми словами (time, money, water) и перед множественным числом (files, emails) — оба слова работают.
  5. После some и any не ставь of без the: some files — «несколько файлов».
  6. Some и any — это не артикли, перед ними не нужно ставить a.

Примеры

  • Sadam has some free time today.У Садама сегодня есть немного свободного времени.
  • Do you have any experience with Java?У тебя есть какой-нибудь опыт с Java?
  • Leyla doesn't need any help with the report.Лейле не нужна никакая помощь с отчётом.
  • Would you like some tea before the meeting?Хочешь немного чая перед встречей?
  • We have some questions about the contract.У нас есть несколько вопросов по контракту.
  • I don't have any money on my card right now.У меня сейчас нет денег на карте.

Частые ошибки

I have any questions.
I have some questions.
В утверждении нужен some, а не any.
Do you have some experience?
Do you have any experience?
В обычном вопросе ставим any.
Do you need a some help?
Do you need some help?
Перед some артикль a не ставим.

Проверь себя

  1. Ramil has ___ questions about the project.

  2. Do you have ___ experience with databases?

  3. Guzel doesn't have ___ time today.

  4. Would you like ___ coffee?

  5. We need ___ new files for the test.
